## ✨ Features

- Animated starfield & shooting stars background
- Custom cursor with trailing ring
- Tab-switching between App Dev and Web Dev profiles
- Downloadable CV — switches PDF based on active tab
- Scroll reveal animations & parallax planets
- GitHub stats, contribution graph & streak
- Fully responsive design
